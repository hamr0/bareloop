# docs — navigation

Five tiers. Two records sit at this root because everything cites them.

- **`FINDINGS.md`** — this repo's findings, F1 onward. Every friction point gets logged,
  grounded in source or event log. No papering over.
- **`UPSTREAM-ASKS.md`** — lib gaps filed against the bare suite. Every request-red doubles
  as an upstream finding.
