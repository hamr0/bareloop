P9 v2: the runs list, copied from fwdloop M11 (with Scheduled)

Cards, colours, header style, date format, clipping and fold rules are fwdloop's as built (v0.19.0). Click a Running now or Needs you card to select its run and scroll to its job. Click a run card to select it. Open "older runs" on flights-b to see 7, then "use search". Type run-2 in the search box: the fold opens and the matched run is marked with a blue bar (not selected). The Scheduled section is drawn after Needs you as fwdloop built it: click a card to open that job's newest run (the Run tab); filters and search never touch it. P9 builds only the empty slot; the triggers piece (PRD v1.99) fills it.

  • Header: bold, normal case, 12 px, with the count. Jobs adds "run in the last 30 days".
  • Running now: line 1 [▶] job run-N wall · $ (wall counts up in place); line 2 the plain why.
  • Needs you: blue border, pill at the right (label, not a button), line 2 why · MM/DD HH:MM. Accept is drawn so the final shape is visible; it is built only when the Run tab has an Accept control. Resume is built now and ages out after 7 days.
  • Job card: [sign] job · k runs · check type / word · why; not clickable; blue when the selected run is inside it.
  • Run card: [sign] run-N MM/DD HH:MM · model / word — why · $ · wall. Unknown cost reads "unknown".
  • Scheduled (N), after Needs you: [·] job <today 15:00 | tomorrow 09:00 | Tue 20 Oct, 09:05> / next in 3h · schedule words. Soonest first; a file-trigger job has no clock time, so it shows only its words and sorts last. A click opens the job's newest run on the Run tab. Not touched by filters or search. Built with the triggers piece (PRD v1.99); P9 builds the empty slot. No Workflows / History switch.
